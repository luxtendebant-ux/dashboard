# Комплаенс · Станок-качалка 4.0

Автономный интерактивный дашборд текущих задач комплаенс-отдела. Откройте `index.html` либо https://luxtendebant-ux.github.io/dashboard/.

## Изменения

Автомобиль заменён станком-качалкой. В HTML встроен именно рисунок из файла `images.jpg`, предоставленного пользователем. Его пиксели разделены масками на основание, опоры, привод, балансир с головкой и скважинный узел. Клетчатый фон отделяется при подготовке слоёв. Анимация использует присланный рисунок.

Пять групп деталей собираются по прогрессу задач. В ДЕМО каждой задаче соответствует группа узлов; в рабочих проектах задачи распределяются между группами. После завершения всех задач и соединения деталей запускается насос. Кривошип вращается, шатун передаёт движение балансиру, головка и шток совершают согласованный ход; в трубопроводе показано движение нефти. Насос продолжает работать после завершения ДЕМО. Доступна отдельная пауза.

Механика рассчитывается как четырёхзвенный механизм с постоянными длинами звеньев. Период — 5 секунд. Точное совпадение с роликом https://www.youtube.com/watch?v=HkHOQvA6l5s&t=131s не подтверждено: просмотр видео был заблокирован контролем доступа.

При создании и редактировании задачи доступно поле **«ФИО исполнителя»**. Введите имя вручную или выберите существующего сотрудника из подсказок. Новое имя добавляется в команду вместе с сохранением задачи. Регистр букв и повторные пробелы учитываются при поиске дублей. Пустое поле оставляет задачу без исполнителя. Назначение сотрудника отменяется вместе с сохранением задачи.

Название слева от рисунка редактируется вручную: название выбранной задачи, комплексной задачи либо общей доски. Пустое название отклоняется. Изменение в шапке синхронизируется с открытым черновиком карточки.

## Возможности

- Задачи, соисполнители, согласующий, контрольные шаги с ответственными и сроками, комментарии от выбранного автора.
- Комплексные задачи руководителя с общим сроком, критерием результата и подзадачами команды.
- Перенос задач между этапами, свободное размещение, перестановка модулей, отчётов и строк локальных данных.
- Маршрут и диаграмма Ганта, параллельные ветви, критический путь, перенос и изменение длительности полос мышью. Календарь Пн–Пт без праздников; циклы и раннее завершение зависимых задач блокируются.
- ДЕМО для пяти сотрудников, семь рабочих дней, параллельные ветви. Пауза, скорость, следующий этап, повтор и возврат к исходной доске.
- Обмен через JSON, объединение правок, выбор конфликтующих версий с сохранением комментариев, защищённые копии AES-GCM, отмена и повтор действий.

## Данные и запуск

Весь код и рисунок находятся в одном HTML. Внешние библиотеки и сетевые запросы не нужны. Данные задач не отправляются на сервер. Локальное сохранение включается отдельно. Выбор автора — подпись действия, а не аутентификация. Онлайн-синхронизация и серверное разграничение прав не подключены. Обычный JSON содержит открытые данные.

Насос визуализирует готовность задач. Дашборд не проверяет актуальные санкционные списки и не выдаёт юридическое разрешение на участие в мероприятии.

В браузерах без Canvas остаётся исходный рисунок и доступна доска. При настройке уменьшенного движения насос первоначально остановлен; его можно запустить кнопкой.

`TESTING.md` описывает 49 выполненных проверок и их границы.
