# Юридическое рабочее пространство · W12 5.1

Тестовый проект для юридического отдела, комплаенса и международных задач. Цвета интерфейса сохранены: тёмный зелёный, светлые поверхности, мятные и золотистые акценты.

## Быстрый запуск

Откройте **index.html** в современном браузере. Код приложения, ExcelJS 4.4.0 и Three.js 0.160.1 встроены в файл. Для автономного режима установка и интернет не нужны. Изменения и черновики сохраняются в текущем браузере; перенос выполняется через Excel и JSON.

Нажмите **ДЕМО** на сводке или странице двигателя. Пять участников проходят 34 реальные команды создания результата, выполнения шагов и приёмки. Работа изолирована от ваших данных. После приёмки пяти задач и общего результата двигатель запускается. Выход из ДЕМО восстанавливает исходное пространство.

## Свободный доступ в опубликованной версии

Пароль администратора настроен как солёный PBKDF2-SHA256-проверочный результат. Проверка пароля отключена по умолчанию. Создание и изменение задач, дел, сотрудников, шаблонов и календарей доступны без пароля при выборе любого активного автора. Порядок выполнения, контрольные шаги и проверка зависимостей продолжают работать.

Кнопка «Доступ открыт» показывает текущий режим. Для последующего включения проверки задайте enabled: true в admin-verifier.json и пересоберите index.html командой npm run build. Сам пароль в HTML, данных задач и экспортируемых файлах не сохраняется.

Открытый режим относится к автономной опубликованной демоверсии. При подключении к Excel-сервису действуют серверные учётные записи.

## Работа отдела

- **Юридическое дело** хранит направление, цель, руководителя, юрисдикции, языки, часовой пояс, сроки и доступ участников.
- **Простая задача** имеет конкретный результат, исполнителя, согласующего и контрольные шаги с весами, ответственными и датами.
- **Комплексная задача** объединяет подзадачи. Её приёмка требует принятых обязательных подзадач и заполненного общего результата.
- **Контрольная точка** фиксирует самостоятельный результат без обязательного чек-листа.
- Шаблоны доступны для договоров, заключений, претензий, судебных дел, корпоративных процедур, международных задач и комплаенса.
- ФИО можно вписать вручную: новый сотрудник появится в команде, повторное имя с лишними пробелами не создаст дубль.

Маршрут: **Входящие → В работе → На согласовании → Принято**. Есть ожидание с причиной и датой следующего контакта, отмена и возврат в работу. Приёмку выполняет назначенный согласующий. Изменение принятого результата или его документов требует новой приёмки. Готовность чек-листа и приёмка показаны отдельно.

Зависимости поддерживают запуск после всех или любого из предшественников. Гант показывает исходный план, прогноз по рабочему календарю, критический путь и внешние даты. Полосы можно переносить и растягивать мышью; карточки доступны с клавиатуры. Внешняя дата не сдвигается автоматически. Праздники и выходные настраиваются; специальные юридические правила исчисления сроков задаются организацией.

## Excel и JSON

Из карточки задачи можно открыть экспорт на любом этапе. Для комплексной задачи выгружаются подзадачи и связанные данные. Доступны:

- **Отчёт на дату** — фиксированная дата расчётов, текущие статусы и история.
- **Рабочая копия** — для изменений и возврата с предварительным просмотром и выбором конфликтующих версий.
- **Основная книга Excel** — всё пространство в связанных таблицах.

Приложение создаёт 17 листов: карточку, задачи, дела, сотрудников, шаги, связи, назначения, согласования, документы, комментарии, историю, календари, шаблоны, внешние связи, расчёты, параметры и исходные версии. Таблицы, фильтры, закрепление строк, форматы, проверки значений и формулы вставляются автоматически. Итоги уже рассчитаны; Excel также пересчитывает формулы при открытии и изменении входных ячеек.

Строка 1 содержит стабильные ключи, строка 2 — понятные названия колонок. Для возврата сохраняйте ID, названия листов и порядок ключевых колонок. Числовые веса и выполнение шагов влияют на расчёты. Иерархию и маршрут удобнее менять в дашборде, затем формировать новую рабочую копию. Изменение официального статуса проверяется при импорте. Записи согласований в файле не заменяют решение согласующего.

JSON предыдущей версии дашборда импортируется как отдельное локальное пространство. Имена, задачи, шаги, связи, комментарии и журнал переносятся. Согласования помечаются как исторические записи старого клиентского интерфейса. Перед заменой пространства требуется подтверждение; доступна отмена.

Вложения хранятся отдельно. Экспорт содержит пути и версии документов; сами файлы документов в Excel и JSON не упаковываются.

## Общая Excel-книга для 2–10 сотрудников

Для совместной записи запустите сервис из этого проекта на одном корпоративном компьютере или сервере с Node.js 20+:

```powershell
npm install
npm start -- --data-dir "\\server\legal\dashboard"
```

По умолчанию сервис доступен на **http://127.0.0.1:8790**. Он сам отдаёт index.html. Во вкладке «Excel и обмен» нажмите «Подключить Excel-сервис». Индивидуальные тестовые коды входа для сотрудников показываются в консоли сервера и обновляются после перезапуска.

Сервис сохраняет книгу `Работа_юридического_отдела.xlsx`, создаёт резервную копию, проверяет временный файл перед заменой, ведёт очередь записи и отклоняет устаревшие версии. Повтор запроса с тем же ID не создаёт дубликат. Другой экземпляр сервиса не может занять ту же папку. Внешнее изменение книги обнаруживается до перезаписи. Обновления коллег подхватываются автоматически, если карточка не открыта; открытый черновик сохраняется для проверки различий.

Для ручного редактирования основной книги остановите сервис, сохраните резервную копию и проверьте файл перед повторным запуском. При аварийном завершении проверьте отсутствие работающего процесса перед удалением оставшегося `.legal-workspace.lock`.

Для доступа с других рабочих мест IT-служба настраивает адрес прослушивания (`HOST`), HTTPS, доступ сервиса к сетевой папке и корпоративную аутентификацию. В комплекте реализованы тестовые индивидуальные коды, серверные проверки ролей, HttpOnly-сессии и CSRF. Корпоративный SSO не настроен. Выбор автора в автономном HTML — режим тестирования, а не аутентификация.

## Двигатель W12

Четыре ряда по три цилиндра, 12 поршней и шатунов, шесть кривошипов, клапаны, привод и топливная рампа. Детали соединяются по принятым задачам. Двигатель работает после приёмки общего результата. Можно вращать модель мышью, открывать сечение, менять скорость и ставить на паузу. Труба питания сохранена; маркеры потока движутся по её геометрии.

Это учебная кинематическая модель W12. Она не является заводской CAD-моделью конкретного двигателя Mercedes. Просмотр указанного YouTube-фрагмента через браузер был недоступен, поэтому точное визуальное совпадение с видео не подтверждено. При отсутствии WebGL доступна схема с теми же 12 цилиндрами и расчётом движения.
