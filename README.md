# Комплаенс · Veyron Workshop

Интерактивная рабочая доска комплаенс-отдела. Запуск: открыть `index.html` в современном браузере или перейти на https://luxtendebant-ux.github.io/dashboard/.

## Что изменено в версии 3.0

- Полностью убраны присланные фотографии и фрагменты фотографий. Машина построена программно из собственной геометрии по мотивам Bugatti Veyron: округлые пропорции, подковообразная решётка, дугообразная крыша, боковые воздухозаборники, четыре задних фонаря.
- 18 отдельных узлов собираются последовательно за 11 секунд: рама, подвески, W16, четыре колеса, кузов, двери, салон, остекление, крыша, светотехника и воздуховоды. Детали движутся по плавной траектории и остаются непрозрачными; стекло имеет собственную прозрачность.
- Поездка длится 7 секунд. Путь непрерывный, скорость плавно нарастает и снижается, вращение колёс рассчитывается из пройденного расстояния. Камера сопровождает машину без случайных смещений и тряски.
- Название слева от модели задаётся вручную. При выборе задачи редактируется её название, при выборе комплексной задачи — название проекта. Для общей доски без выбранного проекта редактируется название доски. Изменение применяется после выхода из поля; пустое название отклоняется. Работает отмена.
- Завершение всех задач выбранного проекта запускает сборку и финиш. Выбор одной выполненной подзадачи не означает завершение незаконченного проекта.

## Работа с доской

Создавайте задачи, назначайте исполнителя, соисполнителей и согласующего. Добавляйте шаги, ответственных за шаги, сроки, комментарии и данные локальных отчётов. Комплексная задача объединяет подзадачи команды и имеет руководителя, срок и критерий результата.

Задачи переносятся между этапами за маркер ⠿. В свободном режиме доступны перемещения на поле; можно менять расположение модулей и строк отчётов. Альтернатива мыши — выбор задачи и кнопки перемещения.

Во вкладке «Маршрут и Гант» показаны предшественники, параллельные ветви, сроки и критический путь. Рабочий календарь: понедельник–пятница, без государственных праздников. Полосы можно переносить и растягивать; циклические зависимости и завершение до предшественников отклоняются.

Кнопка «ДЕМО» запускает отдельный пример из пяти человек: сбор данных, проверка организатора и оплаты, проверка материалов, подготовка досье, итоговое решение руководителя. Две ветви выполняются параллельно, общий срок — семь рабочих дней. После выполнения задач показываются сборка машины и поездка к цели. Доступны пауза, скорость, следующий этап, перезапуск и переход к диаграмме Ганта. Возврат восстанавливает исходную доску и историю отмены.

## Данные и совместная работа

Это автономный HTML, без сервера и сетевых запросов. Выбор автора определяет подпись действий и комментариев, но не является аутентификацией. Одновременная онлайн-синхронизация и серверное разграничение прав не подключены.

Обмен между сотрудниками выполняется через JSON-файлы. При объединении правок конфликтующие версии выбираются пользователем, комментарии сохраняются. Доступна защищённая копия AES-GCM. Обычный JSON не зашифрован. Сохранение в текущем браузере включается пользователем отдельно. Не загружайте рабочие файлы в публичный репозиторий.

Модель отображается в WebGL; при его недоступности программа проецирует ту же геометрию через Canvas 2D. При отсутствии обоих API остаётся собственный силуэт, а функции доски доступны. Сборка и поездка — визуализация результата задач, а не автоматическое санкционное заключение или проверка актуальных санкционных списков.
